# Аниме Топ 2026

Курируемый рейтинг 55+ аниме (преимущественно isekai / фэнтези) на основе данных MyAnimeList. Одна статическая страница на Astro с полным интерактивом на ванильном JS.

## Технологии

- **Astro v5** — статическая генерация (SSG)
- **Tailwind CSS v4** — утилитарная стилизация через `@tailwindcss/vite`
- **Vanilla JS** — вся интерактивность (без React/Vue/Svelte)
- **Font Awesome 6** — иконки

## Быстрый старт

```bash
npm install
npm run dev         # разработка на localhost
npm run build       # сборка в dist/
npm run preview     # просмотр собранной версии
```

## Архитектура

### Страницы
Единственная страница `src/pages/index.astro` содержит 6 вкладок:

| Вкладка | Содержимое | Компонент |
|---------|-----------|-----------|
| popularity | 55 карточек аниме с сортировкой | `AnimeCard` |
| imba | 7 самых имба главных героев | `InfoCard` (type=imba) |
| characters | 10 лучших персонажей | `InfoCard` (type=characters) |
| ecchi | 7 тайтлов по уровню фансервиса | `InfoCard` (type=ecchi) |
| cute | 7 милых героев | `InfoCard` (type=cute) |
| ln | 20 лайт-новелл | `LnCard` |

### Интерактивность (Vanilla JS)
Вся логика в `src/scripts/`, импортируется через `<script>` в `index.astro`:

- **tabs.js** — переключение вкладок с анимацией exit/enter
- **search.js** — поиск с debounce 200ms по всем вкладкам
- **render.js** — фильтрация и сортировка карточек через DOM
- **detail.js** — детальный просмотр аниме + модалка персонажа
- **theme.js** — тёмная/светлая тема с сохранением в localStorage
- **parallax.js** — параллакс фона с учётом `prefers-reduced-motion`
- **random.js** — кнопка случайного аниме с подсветкой
- **tooltip.js** — кастомные тултипы

### Данные
Статические данные в `src/data/` — импортируются и в Astro (на сборке), и в клиентские JS-модули (на运行时).

### Стили
Единый `src/styles/global.css` с CSS-переменными для тёмной и светлой темы.

## Разработка

- Язык интерфейса: **русский**
- Классы Tailwind: статические строки (для JIT-сканирования)
- Для динамических классов — `class:list={[...]}`
- Для динамических стилей — `` style={`... ${var} ...`} ``
- `!important` в CSS не используется (удвоение селектора вместо этого)
- `localStorage` всегда в `try/catch`
