# Дизайн: вкладка «Лоли»

Дата: 2026-08-13
Статус: одобрено пользователем
Версия: 1.0

## Цель

Восстановить вкладку «Лоли» из бета-версии сайта (anime_ranking_v3.html) в текущем проекте (Astro + Tailwind v4), в современном стиле и с расширенным списком тайтлов.

## Решения (согласованы с пользователем)

1. **Название** — «Лоли» (без слова «ребёнок»; бейдж «Субъективно», иконка `fa-child`).
2. **Объём** — все тайтлы проекта (из 56), где есть лоли-персонажи или главные герои с детской внешностью; оценка «LOLI INDEX» 0–100.
3. **Стиль** — как вкладка «Милые герои»/«Экки»: заголовок + бейдж, подзаголовок, SearchBar, грид карточек InfoCard, предупреждающий блок.

## Изменения

1. **`animeData.js`** — новый массив `loliData`: `{ title, reason, level (0-100), note? }`.
2. **`InfoCard.astro`** — новый `type="loli"`: заголовок, причина, «LOLI INDEX» (янтарный), заметка-чип, ранговый бейдж.
3. **`index.astro`** — секция `#content-loli` (hidden, tabpanel) с заголовком «Лоли», бейджем «Субъективно», подзаголовком, SearchBar, гридом `#grid-loli`, предупреждением (янтарное).
4. **`Header.astro`** — кнопка `#tab-loli` (после «Милые герои»).
5. **`tabs.js`** — регистрация вкладки в общем цикле.

## Предупреждение (текст из беты, адаптирован)

«Список составлен на основе внешности персонажей и сюжетных особенностей. Многие тайтлы специально делают взрослого в теле ребёнка для комедийного эффекта. Не путать с "лоли-контентом" в негативном смысле.»

## Проверка

- `npm run build` — OK.
- HTML/Playwright: вкладка видна, переключение работает, карточки рендерятся, поиск фильтрует, предупреждение отображается.
